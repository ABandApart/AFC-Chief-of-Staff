# Template 33: The Shared Background Connection

**Section:** LinkedIn

**When to use it:** Default connection request. Use whenever any shared employer, client, school or community exists.

## Template Text

**Subject:** LinkedIn message, no subject line

```
Hi [First Name], we both came out of [Shared Employer / Program / Community]. Saw [Company Name] closed your round, congrats. I run [function] fractionally now, mostly for companies right after a raise. Would like to connect.
```

## Pro Tip

This is the strongest connection request available and it is missing entirely from most outreach material. Acceptance rates on a shared background anchor run far ahead of anything cold. Teach students to exhaust their own alumni and client networks before they send a single cold request.

## Failure Mode

Stretching the connection. A shared industry is not a shared background, and a founder who checks and finds nothing will decline and remember.
