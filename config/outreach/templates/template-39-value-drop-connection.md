# Template 39: The Value Drop After Connection

**Section:** LinkedIn

**When to use it:** First message when you have a genuinely useful asset and they are unlikely to be ready to buy.

## Template Text

**Subject:** LinkedIn message, no subject line

```
Hey [First Name], thanks for connecting.

I put together a [framework / checklist] on [topic] out of running [function] inside [number] post-raise companies. Given where [Company Name] is right now, it might be worth ten minutes of your time.

[URL]

No ask attached. If it is useful and you want to talk it through, I am here.
```

## Pro Tip

Paste the asset inline where you can. A link inside a LinkedIn message suppresses reach and reads as marketing. The short version in the message with the link underneath performs better than the link alone.

## Failure Mode

Gating it behind a form. On LinkedIn this converts a peer message into a funnel in one click and the founder will read it exactly that way.
