# Template 36: The Mutual Connection Connection

**Section:** LinkedIn

**When to use it:** When a shared contact exists and you have permission to name them.

## Template Text

**Subject:** LinkedIn message, no subject line

```
Hi [First Name], noticed we both know [Mutual Connection]. I run [function] fractionally for funded companies. Congrats on the round, would like to connect.
```

## Pro Tip

Ask the mutual connection first, every time. The upside is that they occasionally offer to introduce you instead, which is worth more than the connection request you were about to send.

## Failure Mode

Naming someone who would not vouch for you. Founders check, and at this stage the network is small enough that they check quickly.
