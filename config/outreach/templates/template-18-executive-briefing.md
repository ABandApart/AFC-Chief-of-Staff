# Template 18: The Executive Briefing

**Section:** Series B and Beyond

**When to use it:** Best cold entry at Series B and above. Works when you have run the same transition multiple times.

## Template Text

**Subject:** [Topic] session for your leadership team

```
Hi [First Name],

I have run [function] through [specific transition] at [number] companies between Series B and C. I put the pattern into a ninety minute working session for leadership teams.

It covers [finding one], [finding two], and [finding three], all of it drawn from engagements rather than research.

There is no pitch inside it. It is the session I wish someone had run for me the first time I did this.

Would that be useful for your team?

[Your Name]

[Title]
```

## Pro Tip

This is how senior operators actually get into large companies. A working session positions you as a peer being consulted rather than a supplier being evaluated, and it puts you in a room with the full leadership team in one move.

## Failure Mode

Running a pitch inside the session anyway. You will get exactly one of these per company and the reputational cost of misusing it travels through the investor network.
