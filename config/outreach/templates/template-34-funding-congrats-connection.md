# Template 34: The Funding Congrats Connection

**Section:** LinkedIn

**When to use it:** Fallback when no shared background, mutual connection or content exists. The weakest option in the pack.

## Template Text

**Subject:** LinkedIn message, no subject line

```
Hi [First Name], saw [Company Name] closed your round, congrats. I run [function] fractionally for companies at your stage. Would like to connect.
```

## Pro Tip

Naming the function in a cold request is what separates this from the hundred other congratulations messages in their queue that week. It is specific, it is not a pitch, and it tells them why you are in their inbox.

## Failure Mode

Using this as the default. It works, but it is the floor. If a student is sending mostly these, the problem is research, not copy.
