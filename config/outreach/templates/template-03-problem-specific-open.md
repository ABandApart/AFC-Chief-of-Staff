# Template 03: The Problem Specific Cold Open

**Section:** Seed Stage

**When to use it:** When a public signal exposes an unowned function.

## Template Text

**Subject:** [Specific problem] at [Company Name]

```
Hi [First Name],

Looking at [Company Name]'s [job postings / site / product] I noticed [observation: two SDR roles open with nobody listed running revenue / no finance lead anywhere on the team page].

That usually means [underlying problem: pipeline gets built before anyone owns the number / you are closing the books yourself at eleven at night].

I run [function] fractionally for seed companies and I have watched that pattern play out enough times to know where it goes.

Fifteen minutes?

[Your Name]
```

## Pro Tip

The compound signal is what makes this work. Hiring individual contributors into a function with no leader is the single strongest seed stage buying signal you can see from outside.

## Failure Mode

Leading with the diagnosis in a way that reads as criticism. You are naming a pattern, not grading their org chart.
