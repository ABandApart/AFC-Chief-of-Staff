# Template 19: The Cost of the Open Seat

**Section:** Series B and Beyond

**When to use it:** When a senior seat is visibly vacant or a search has been running more than sixty days.

## Template Text

**Subject:** What the open [Role Title] seat costs per month

```
Hi [First Name],

Rough arithmetic on the [Role Title] search. At [Company Name]'s size an unowned [function] tends to run somewhere between [low] and [high] a month in [stalled decisions / deferred pipeline / rework], before counting the opportunity cost of whoever is covering it on top of their own job.

I have a model I use to size that properly. It takes about twenty minutes against your actual numbers.

Want me to run it, or send it over for your team to run themselves?

[Your Name]

[Title]
```

## Pro Tip

Offering both options is the mechanic. Sending the model is low friction and still gets you a reply, and a company that runs it themselves has done your qualifying for you.

## Failure Mode

Presenting the estimate as precise. It is arithmetic you did from the outside and you should say so, or the first person who checks it will discard the whole email.
