# Template 07: The Value First, No Ask Email

**Section:** Seed Stage

**When to use it:** Softer entry when the founder is clearly not ready, or as a dead-touch during days fourteen to thirty.

## Template Text

**Subject:** Resource for [Company Name]'s next phase

```
Hi [First Name],

Congrats on the round. Seed is the phase where every function is quietly your job.

I put together a [framework / checklist] on [topic: what to own yourself and what to hand off in your first two quarters post raise]. It comes out of my proprietary method for [function] and it is built on running this inside [number] seed stage companies.

Here it is: [URL]

No ask attached. If it is useful and you want to talk it through, I am here.

[Your Name]
```

## Pro Tip

This is the one template that also works as a LinkedIn message with the asset pasted inline. Adapt rather than duplicate.

## Failure Mode

Gating the resource behind a form. At seed that converts a peer message into a marketing funnel and the founder will read it that way.
