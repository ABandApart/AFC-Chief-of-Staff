# Template 37: The Content or Event Connection

**Section:** LinkedIn

**When to use it:** After a talk, panel, podcast or published piece.

## Template Text

**Subject:** LinkedIn message, no subject line

```
Hi [First Name], caught your [talk at [Event] / piece on [Topic]]. Your point about [specific point] is one I hit repeatedly running [function] at [Company]. Would like to connect.
```

## Pro Tip

This one carries the highest acceptance rate of any request that does not involve a shared background, because it proves attention rather than claiming it.

## Failure Mode

Generic praise. Great talk is worse than no message. Name the specific point or do not send it.
