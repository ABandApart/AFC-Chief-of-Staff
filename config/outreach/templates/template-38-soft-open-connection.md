# Template 38: The Soft Open After Connection

**Section:** LinkedIn

**When to use it:** Default first message. Send at least twenty-four hours after acceptance.

## Template Text

**Subject:** LinkedIn message, no subject line

```
Thanks for connecting, [First Name].

Saw [Company Name] closed recently. Good stretch to be in and a hard one.

I run [function] fractionally, mostly for companies right after a raise. Genuinely curious rather than pitching: what is the biggest thing on your plate as you scale?

Happy to be useful either way.
```

## Pro Tip

The question has to be open enough to answer honestly and narrow enough to be about their business. Their answer tells you which of the three function states you are dealing with, which tells you which template comes next.

## Failure Mode

Following the question with a paragraph about yourself. Ask it and stop. This message should be short enough to read on a phone without scrolling.
