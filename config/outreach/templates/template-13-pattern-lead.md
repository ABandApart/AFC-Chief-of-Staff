# Template 13: The Pattern Lead

**Section:** Series A

**When to use it:** Replaces the data point lead. Use once you have enough engagements to see a real pattern.

## Template Text

**Subject:** [The pattern, stated in one line]

```
Hi [First Name],

Across the [number] Series A companies I have run [function] for, the ones that put a senior owner on the function before the headcount arrives hit their number roughly two quarters earlier than the ones that hire the team first and the leader second.

Small sample. But it has held every time so far.

[One line on the proprietary method you run inside the function.]

Open to hearing how it played out at [Similar Company]?

[Your Name]
```

## Pro Tip

The data has to be yours. A pattern from your own book is more credible at this stage than any industry statistic, because it is specific, checkable, and nobody else can send the same email.

## Failure Mode

Fabricating an industry statistic, which is what the original version of this template invites. A founder who searches for your number and cannot find it is finished with you, and they will search.
