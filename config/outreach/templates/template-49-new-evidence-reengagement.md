# Template 49: The New Evidence Re-engagement

**Section:** Re-engagement

**When to use it:** Replaces the new feature angle. Use when you have done something since you last spoke that changes what you can claim.

## Template Text

**Subject:** Something that changed on my side

```
Hi [First Name],

We connected a while back about [function] at [Company Name].

Since then I [ran the same problem at [Company] and [outcome with a number] / published [the piece] on exactly the thing you were weighing / took [number] more companies through [transition]].

It speaks directly to [the specific concern that stalled the conversation], which is the only reason I am writing.

Worth a fresh look?

[Your Name]
```

## Pro Tip

A person does not ship features, so the fractional version of this is new evidence rather than new capability. Track what stalled each conversation and re-enter only when you can genuinely answer it.

## Failure Mode

Manufacturing the update. If nothing has actually changed since you last spoke, this template is not available to you and Template 48 probably is.
